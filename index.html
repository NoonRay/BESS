Using this Console

  • Use the Sidebar to jump freely between steps.
  • Expand the Instructor Talking Point at the bottom of each step for discussion prompts.
  • Clicking Flag Andon on an out-of-spec batch reading automatically jumps to the Andon section and starts the timer.
  • Keyboard: Use ← and → to navigate steps. Press Esc to close this modal.
  • Click Reset in the header to clear all data for the next class session.
